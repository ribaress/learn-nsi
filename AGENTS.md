# Documentation du projet

- Toujours fournir et maintenir un `README.md` en français.
- Documenter les prérequis, les commandes exactes de lancement, de test, de mise en forme, de compilation et d’aperçu, ainsi que leur rôle et les adresses locales.
- Expliquer le fonctionnement pédagogique, l’organisation du code, la sauvegarde, la publication et les limites connues.
- Mettre le README à jour lorsqu’un changement rend ses commandes ou ses explications obsolètes. Vérifier les commandes dans `package.json` et les scripts existants.
